# CV Assessment Pro 📄✨

A professional, strict CV/Resume assessment tool that evaluates your CV against international hiring standards. Get detailed scores, actionable recommendations, and ensure your resume passes ATS (Applicant Tracking System) filters.

## Features

- 🔍 **8-Category Scoring** — Format, Contact, Summary, Experience, Education, Skills, Language, ATS
- 📊 **S-F Grade System** — Strict grading from Exceptional (S) to Poor (F)
- 🌍 **Regional Standards** — US, UK, EU, Asia hiring conventions
- 📤 **Drag & Drop Upload** — Support for PDF, DOCX, and TXT files
- 💡 **Actionable Recommendations** — Prioritized improvement suggestions
- 📑 **Export Report** — Download your assessment as PDF
- 🌙 **Dark/Light Mode** — Toggle between themes
- 🚀 **100% Client-Side** — No server needed, your CV never leaves your browser

## Scoring Rubric (100 points)

| Category | Weight | What We Check |
|:---|:---:|:---|
| Format & Layout | 15 | Single-column, professional fonts, consistent spacing |
| Contact Information | 10 | Professional email, phone, LinkedIn, location |
| Professional Summary | 10 | Concise career overview with keywords |
| Work Experience | 25 | Action verbs, quantified results, chronological order |
| Education | 10 | Degree, institution, year, relevance |
| Skills & Competencies | 10 | Categorized hard/soft skills, relevance |
| Language & Writing | 10 | Grammar, spelling, professional tone |
| ATS Compatibility | 10 | Standard headers, parseable structure |

## Grade Scale

| Grade | Score | Label |
|:---:|:---:|:---|
| S | 95-100 | Exceptional |
| A | 85-94 | Excellent |
| B | 70-84 | Good |
| C | 55-69 | Average |
| D | 40-54 | Below Average |
| F | 0-39 | Poor |

## Quick Start

1. Clone this repository
2. Open `index.html` in your browser
3. Upload your CV (PDF, DOCX, or TXT)
4. Review your detailed assessment

No build tools or server required!

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- [PDF.js](https://mozilla.github.io/pdf.js/) for PDF parsing
- [Mammoth.js](https://github.com/mwilliamson/mammoth.js) for DOCX parsing
- Canvas API for charts
